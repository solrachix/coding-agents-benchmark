# Bugfix App

Projeto TypeScript/Next.js com defeitos intencionais para o benchmark de manutenção.

O objetivo é diagnosticar os sintomas apresentados pelos comandos de validação e corrigir a causa raiz sem reescrever o projeto nem alterar os testes para facilitar a tarefa.

## Scripts

```bash
npm install
npm run typecheck
npm test
npm run build
npm run lint
```
