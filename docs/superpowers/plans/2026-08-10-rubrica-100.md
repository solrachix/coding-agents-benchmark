# Rubrica 100 Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Substituir o score binário de 70 pontos por uma rubrica auditável de 0–100, preservando o score objetivo histórico.

**Architecture:** Um avaliador estático independente calcula oito dimensões a partir do projeto, das validações e das penalidades. Falhas de harness ficam fora do ranking como `scoreStatus`, enquanto execuções válidas recebem `total`, `objectiveScore`, dimensões, evidências e tier.

**Tech Stack:** TypeScript, Node.js, `node:fs`, Node Test, JSON/Markdown.
