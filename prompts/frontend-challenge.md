## Frontend Challenge

Implemente a interface do dashboard de eventos no projeto fornecido, seguindo a especificação visual em `REFERENCE.md`.

Requisitos:

- preserve Next.js, TypeScript, React e App Router;
- implemente a tela de catálogo/dashboard de eventos para desktop, tablet e mobile;
- mantenha busca, filtros, menu de visualização, modal de detalhes e ação de salvar evento funcionais;
- use HTML semântico, labels acessíveis, foco visível e navegação por teclado;
- organize a tela em componentes reutilizáveis e evite uma implementação monolítica;
- não use uma screenshot, canvas gigante ou SVG único como substituto da interface;
- mantenha typecheck, testes, build e lint funcionando;
- não altere os scripts nem os arquivos de avaliação do benchmark.

Trabalhe autonomamente no diretório atual e deixe a aplicação pronta para ser executada pelo script `start` ou `dev`.
